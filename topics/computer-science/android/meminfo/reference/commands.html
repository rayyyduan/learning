meminfo 命令

`adb shell dumpsys meminfo` 的调用形式。数字单位是 KB。输出随 Android 版本变化。

两条报告

命令报告
adb shell dumpsys meminfo整机快照：总内存、空闲内存，进程按 PSS 排列
adb shell dumpsys meminfo <package|pid>这一个进程此刻的分配表

包名和 pid 二选一。例如 com.google.android.apps.maps，或 pidof 得到的数字。

已在官方文档里出现的标志

标志作用出处
-d多打 Dalvik / ART 的明细（.Heap、.LOS、.GC 等）dumpsys
-a附上各段内存映射的细目Quick assessment tools
-s只留分类摘要同上
-h打印这份服务支持的全部标志dumpsys

和 procstats 的分工

meminfo 是某一时刻的一张表。adb shell dumpsys procstats --hours 3 才是过去几小时的抽样。两份报告回答的问题不同。

单进程表怎么读，见 第 1 课：两条命令。
